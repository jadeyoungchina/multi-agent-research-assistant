## 暴露的问题

- 020：Writer 在 ID 列表中重复生成 `Cite:ref_0003`，一次修正后仍失败。
- 019：Researcher 将证据原文填进证据 ID 列表，校验器正确拒绝。
- 004：输出达到预先规定的 4096 token 上限，记录为截断失败。
- 10 份单轮/单智能体答案含畸形引用。旧实现只验证声明的 ID，允许这些
  答案以执行成功结束；多智能体此前执行了更严格的正文校验。因此报告
  补充**事后、跨流程统一**的格式诊断，不重标历史执行，也不把 ID 有效
  当成引用支持。两条简单 RAG 流程各只有 15/20 份正文通过精确语法校验。
- 最终渲染层仍会追加 Critic 原话，导致内部标签和重复局限说明出现。
- 闭卷模型虚构微秒延迟、倒置 alias_priority、错误推荐异常处理器；
  RAG 也有误拒答、缺少正文引用和错误的编辑器行为解释。

引用评分 v2 审核每个固定 Markdown 块，语义支持必须覆盖块内全部事实。
它与旧五题的原子主张口径不同，不直接比较两轮引用率。即使引用格式正确，
同样可能引用了不能完整支持结论的段落；多智能体在本轮就出现了此问题。
