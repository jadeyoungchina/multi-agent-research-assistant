# Project review path

| Review goal | Start here |
| --- | --- |
| Understand the project in two minutes | [English project brief](project-brief.md) |
| Run the actual software flow | [One-command offline demo](demo-guide.md) |
| Check ordinary configured startup | [Post-experiment startup repair and acceptance](../engineering/post-evaluation-maintenance.md) |
| Inspect the report and source UI | [Demo screenshots and browser verification](demo-guide.md#capture-the-real-browser-workflow) |
| Prepare a short explanation | [Three-minute walkthrough and questions](presentation.zh-CN.md) |
| Assess engineering decisions and provenance | [Technical report](../technical-report.md), [upstream notices](../../THIRD_PARTY_NOTICES.md) |
| Inspect real-model evidence | [Held-out report](../evaluation/heldout-test/RESULTS.md), [failure cases](../evaluation/heldout-test/FAILURE-CASES.md) |
| Recompute the saved experiment | [Executed notebook](../../output/jupyter-notebook/real-evaluation-analysis.ipynb), [reproduction guide](../evaluation/heldout-test/REPRODUCE.md) |

The runnable demonstration uses deterministic fake providers. The 480-execution
real-model experiment is separate and uses AI-assisted references and scoring.
Further human review was excluded from this delivery at the user's request;
human validation remains zero and is documented as a methodological limitation.

The current presentation is delivered through the bilingual repository README,
saved figures/screenshots, written materials and the local demonstration.
Public hosting and a recorded demo video are outside the delivery scope.
